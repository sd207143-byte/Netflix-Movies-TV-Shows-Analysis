# Netflix Movies & TV Shows Analysis

## Project Overview
This project analyses the Netflix Movies & TV Shows dataset using Python.

## Tools Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn
- GitHub

## Dataset
- netflix_titles.csv

## Analysis Performed
- Movies vs TV Shows
- Top 10 Countries
- Ratings Analysis
- Release Year Analysis
- Genres Analysis
- Duration Analysis
- Year Added Analysis

## Conclusion
This project helps understand Netflix content using data visualisation and Python.
